How this works: each person logs in and sees only the sections their role & team allow — and within a section, only the folders meant for them (their office, their brand). What they can do is set per section: view, add files, edit, or manage. Admins set all of this in the Admin console.

Two-way with your Microsoft drive: documents live on SharePoint/OneDrive and the hub links to them. Change a file on the drive → it shows here (and editors get notified). Update data or a doc from inside the hub → it writes back to the same file on the drive. One source of truth, never a second copy to keep in sync.
